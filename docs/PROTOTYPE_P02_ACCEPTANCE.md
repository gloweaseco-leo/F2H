# 艾夫尔·贸合 F2H P0.2 原型升级验收报告

## 目标
在冻结业务架构 V0.8 范围内，将 P0.1 运营后台型原型升级为「商业价值体验型原型」。**本轮不实现真实系统。**

## 明确交付
1. 首页三角色入口：海外买方、中国供应商、生态运营方；进入同一个跨境业务故事但展示角色任务与可操作权限。
2. 单一完整故事：沙特低糖冻干果蔬 OEM 采购情境，五步连续引导。
3. 采购条件实时改变：采购量、最大交期、清真认证要求、英文包装要求；展示四家纯虚构供应商的 `qualified/pending/blocked`，逐项列出原因。
4. 模拟证据：来源、时间、待核实项；模拟运营方复核，不表示真实认证。
5. 双边授权：买方和供应方分别同意或拒绝；未满足双边同意/审核不得进入引荐模拟。
6. 商务协作的成功推进/受阻两种结果路径，运营视角才能模拟里程碑完成。
7. 本地状态重置、一键重新体验、响应式布局；保留 P0.1 七个业务视图。

## 禁止范围
未调用真实模型、未接入数据库、未建立真实账号、未进行任何真实主体/贸易合规核验、未发送邮件或WhatsApp、未建立真实交易、无付款、无CRM或Vey2GE/L2M数据共享。

## 验收命令
`npm run test` / `npm run build`；浏览器检查脚本（本地单页注入脚本、Chrome）位于 `scripts/browser_check.py`，用于验证模拟交互，不提供真实外部端到端检验。

## 必须通过的门禁
- 匹配规则同时覆盖合格/未知/不满足，并有可解释的业务条件；
- 清真材料未知不能被判为已符合强制认证条件；
- MOQ、交期、包装条件变化应改变结果并撤销既有模拟审批；
- 运营方复核后双方各自同意，才可进入模拟合作；
- 任一方拒绝必须阻止引荐，不能只靠前端按钮显示防护；
- 桌面与手机全流程可操作，浏览器控制台无未捕获错误；
- 正式 `main`、`maohe.baogaoye.cn` 不受影响，PR/Preview 只供验收。

## 复核提示
样本中的“模拟材料已复核”并不代表现实供应商资质真实、有效或合法。`confirmed` 类模拟状态也不代表已经发生真实商务会议。所有评分/流程仅供业务和UI原型验证。
