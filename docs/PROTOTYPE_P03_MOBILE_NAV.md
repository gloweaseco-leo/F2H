# F2H P0.3｜手机端角色化底部导航（仅原型）

- 版本：P0.3 Preview，基于P0.2；不可冒充真实登录/业务系统。
- 适用：仅`max-width:690px`的手机视口；桌面和平板不调整P0.2布局。
- 顶部：持久提示“当前正在体验 · 点击切换角色”，明确显示当前买方／供应方／平台方，点击弹出三身份说明及选择。
- 底部：按角色动态展示5个任务入口，包含“更多”，可访问完整原型旧页面。导航随P0.2共享角色与步骤状态改变。
- 买方：首页／我的采购／找供应商／合作／更多；供方：首页／海外商机／供货能力／合作／更多；平台方：总览／待审核／智能撮合／协作管理／更多。
- 场景：继续复用P0.2沙特食品采购五步虚构流程及共享本地状态，切换视角不替另一方批准，不能经底部导航跳过证据审核和双向同意。
- 页面：复用原P0.2页面，通过手机角色提示卡引导不同任务；不伪装成独立账户界面。
- UI：底部固定栏含安全区留白，角色切换为可关闭弹层，键盘Escape/Tab处理；手机页面内容留出固定栏空间。
- 核验：静态node单测、P0.2回归测试、移动浏览器角色切换和五步交互、桌面像素与可访问性回归；Preview单独发布，不合并生产。
- 明确不做：真实登录、多租户后端、数据库、真实LLM、真实联系方式披露、对外消息、交易。
